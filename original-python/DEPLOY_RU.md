# Пошаговая инструкция: как опубликовать игру в Telegram

## Часть 1. Создать бота
1. Открой Telegram и найди **@BotFather**.
2. Нажми Start и отправь `/newbot`.
3. Введи отображаемое имя, например `King of Farmer`.
4. Придумай username, который заканчивается на `bot`, например `KingOfFarmerPlayBot` (доступность нужно проверить в Telegram).
5. BotFather выдаст токен. Скопируй его в безопасное место. Это пароль от управления ботом — никому его не показывай.
6. Не присылай токен в чат. Вставь его только в переменную окружения `BOT_TOKEN` на хостинге.

## Часть 2. Опубликовать Mini App по HTTPS
Telegram должен открыть игру по общедоступному HTTPS-адресу. Для первого теста можно использовать статический хостинг (например, Cloudflare Pages, Netlify или GitHub Pages) для папки `web/`. Для настоящей игры нужен также сервер `bot/` с постоянным хранилищем.

Самый простой вариант для новичка:
1. Создай аккаунт на хостинге, который поддерживает Python web services и постоянное хранилище/managed database.
2. Загрузи содержимое этого проекта в приватный GitHub-репозиторий или подключи репозиторий к хостингу.
3. Создай Web Service. Build/install command: `pip install -r requirements.txt`.
4. Start command: `uvicorn bot.main:app --host 0.0.0.0 --port $PORT`.
5. Добавь переменные окружения `BOT_TOKEN`, `APP_URL`, `DATABASE_PATH`. `APP_URL` — публичный HTTPS адрес фронтенда. Для `DATABASE_PATH` используй путь на постоянном диске, если хостинг это поддерживает.
6. Для фронтенда опубликуй папку `web/` как статический сайт. Если у хостинга есть единый сервис, можно настроить его раздачу, но тогда проверь CORS/маршруты и укажи корректный `APP_URL`.

Важно: URL фронтенда и API в этом прототипе должны быть согласованы. В `web/app.js` есть `API_BASE`. После публикации укажи там HTTPS-адрес API (пустая строка работает только если API и фронтенд находятся на одном домене).

## Часть 3. Подключить игру через BotFather
1. Открой `@BotFather`, отправь `/mybots`.
2. Выбери своего бота.
3. Открой `Bot Settings` → `Menu Button` → `Configure menu button` (названия пунктов могут немного отличаться).
4. Укажи URL фронтенда с HTTPS и текст кнопки `Играть`.
5. По желанию настрой Main Mini App через раздел настройки Mini App в BotFather, чтобы на профиле бота появилась заметная кнопка запуска.
6. Открой своего бота и нажми Start. Затем нажми «Играть».

## Часть 4. Проверить перед приглашением игроков
- Открой игру на iPhone и Android, если возможно.
- Проверь сбор урожая, посадку, улучшение и перезапуск: прогресс должен сохраниться.
- Проверь, что при обычном открытии сайта вне Telegram показывается предупреждение.
- Проверь логи сервера и ошибки сети.
- Не объявляй публичный запуск, пока не настроены резервные копии, мониторинг, ограничения действий и политика конфиденциальности.

## Можно ли сразу сделать общедоступным?
Да, технически бот можно создать и дать людям ссылку `https://t.me/USERNAME`. Но эта сборка — ранний MVP: сначала рекомендуются закрытые тесты на нескольких аккаунтах. «Создать бота» не означает, что Telegram автоматически продвигает его всем пользователям. Публичная доступность начинается после того, как ты сам распространишь ссылку.

## Если что-то не работает
- `Unauthorized` / бот молчит: проверь `BOT_TOKEN` и логи сервера.
- Кнопка открывает пустую страницу: проверь HTTPS URL и доступность сайта без входа в аккаунт хостинга.
- Игра открывается, но не загружает профиль: проверь `API_BASE`, CORS и логи API.
- После перезапуска пропадают данные: база находится не на постоянном диске.
- Telegram не распознаёт Mini App: проверь, что URL задан через BotFather и использует HTTPS.
