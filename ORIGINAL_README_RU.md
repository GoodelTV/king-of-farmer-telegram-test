# King of Farmer — Telegram Mini App (MVP)

Это стартовая рабочая версия Telegram-игры, созданная отдельно от iOS-приложения. Она не переносит Swift-код напрямую: интерфейс Mini App сделан на HTML/CSS/JavaScript, а сохранение прогресса — на Python + SQLite.

## Что уже реализовано
- Telegram-бот с `/start`, кнопкой «Играть» и `/help`.
- Мобильный игровой экран в стиле средневековой стратегии/фермы.
- Серверное сохранение прогресса по Telegram user ID.
- Ресурсы, уровень, опыт, таймер урожая, сбор урожая, посадка, улучшение ратуши.
- Проверка подписи `Telegram.WebApp.initData` на сервере (в production не доверяйте `initDataUnsafe`).
- SQLite, чтобы прогресс переживал перезапуск процесса (для постоянного продакшна используйте persistent disk/managed DB).

## Чего пока нет
Это MVP, а не копия закрытой игры и не финальная коммерческая версия. Пока нет полноценной боевой системы, PvP, кланов, платежей, античита с расширенными лимитами, административной панели, резервного копирования и масштабирования. Графика — CSS-прототип, игровые механики и стиль можно последовательно улучшать. Не используйте чужие игровые изображения/логотипы без разрешения.

## Структура
- `web/` — клиентская часть Telegram Mini App.
- `bot/` — Telegram-бот + API + SQLite.
- `.env.example` — нужные переменные окружения.
- `DEPLOY_RU.md` — инструкция по запуску и публикации.

## Запуск локально
Требуется Python 3.11+ и публичный HTTPS URL для открытия Mini App в Telegram. Для локальной разработки можно использовать туннель HTTPS (например, Cloudflare Tunnel/ngrok), но не публикуйте токен бота.

1. Скопируйте `.env.example` в `.env` и заполните значения.
2. В терминале из корня проекта:
   `python3 -m venv .venv`
   `source .venv/bin/activate`
   `pip install -r requirements.txt`
3. `uvicorn bot.main:app --host 0.0.0.0 --port 8000`
4. Настройте `APP_URL` на публичный HTTPS адрес папки `web/` (см. DEPLOY_RU.md). Для простого теста можно раздавать `web/` через отдельный HTTPS static host.
5. В BotFather настройте кнопку Mini App с этим URL.

Внимание: бот и API должны иметь доступ к одному и тому же `BOT_TOKEN`, а `APP_URL` должен быть доступен Telegram по HTTPS.

## Безопасность
- Никогда не загружайте `.env` в публичный репозиторий.
- Не отправляйте BOT_TOKEN никому и не вставляйте его в JavaScript/HTML.
- В production используйте HTTPS, persistent storage и резервные копии.
- В Telegram Mini Apps сервер проверяет `initData`; не используйте данные `initDataUnsafe` как доказательство личности.
